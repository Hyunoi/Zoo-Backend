# Synapse X
> [2025. 02. ~ 2025. 04. (약 2개월)]

**기록 기반 네트워킹 기능 중심 컨퍼런스 통합 운영 서비스입니다**.

온/오프라인에서 강연을 듣고 참가자의 인사이트를 기록하고 공유합니다.

참가자 서로와 강연자가 연결될 수 있는 네트워킹의 시작점을 제공합니다.

## 기여한 부분
- **컨퍼런스 참가권 결제 기능 제작**
    
    카카오페이 API (결제 승인, 취소, 승인) 사용
    
    비회원/회원 구매 분기를 나누어 결제 진행하도록 구현
    
    트랜잭션 적용 (결제 실패 시에 결제 취소로 자동 롤백되도록 처리)
    
    Redis 사용하여 결제 요청 시 TID 보유하고 있다가 일정 시간 지난 뒤에 TID 삭제되며 결제 실패하도록 구현
    
- **참가권 결제 시 확인 메일 전송 기능 제작**
    
    MailSender 사용
    
    회원/비회원의 입력 이메일로 확인 메일 전송
    
    참가자가 선택한 세션 목록과 결제 가격 반영하여 메일 내용 구성
    
- **QR 이용한 컨퍼런스 입장 체크 기능 제작**
    
    ZXING 라이브러리 사용
    
    QR 이미지 제작 후 해당 QR 이용하여 참가자의 컨퍼런스 입장 유무를 체크하는 용도로 사용되도록 구현
